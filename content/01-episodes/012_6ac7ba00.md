### 1. 一句话概括
郭宇从 2015 年在字节第一次接触神经网络驱动的产品讲起，回顾抖音如何意外胜出、火山与 Musical.ly 的合并、50 元获客成本与疫情后落脚东京，进而讨论 Vibe Coding 的真实代价、Agent OS、智能的五层商品化、Everything is Media，以及当软件像牛奶一样便宜、工作不再是必选项时，年轻人为何不应再守着一支下跌的股票。

### 2. 节目信息
节目为 INDIGO TALK EP52，主播是 Indigo，嘉宾是郭宇，简介中称其为字节跳动前资深员工/退休程序员。节目发布信息标注为 2026-10-09，时长 4328 秒，约 72 分钟；图文总结链接为 www.indigox.me/indigo-talk-ep-52/。节目背景围绕“当软件像牛奶一样便宜，我们还要交付什么？”展开，时间线从 2015 年郭宇在字节见到 AI 驱动产品，延伸到十年后他在东京一个人用 Agent 做出三十多个产品并陷入倦怠。对谈还涉及抖音早期、Vibe Coding、Agent OS、智能五层次、2% Pro User、软件商品化、工业革命与文艺复兴之争，以及给年轻人的选择建议。

### 3. 章节要点

#### 3.1 从支付宝、Bitcoin 到加入字节：2011—2017
郭宇自述 2011 年在支付宝工作，这是他的第一份中国科技行业经历；2013 年他在支付宝做分享会时第一次接触 Bitcoin，当时价格约 100 美元。2013 年中国移动互联网开始爆发，很多人从南方科技城市涌向北京，OPPO、VIVO 等公司也在这一波中崛起；他因人生转变在 2014 年去北京加入朋友创业公司“多说和图虫”，在中关村苏州街打地铺约 10 个月。这家公司有微博基金投资，后来被今日头条收购，也成为微博早期投字节的一种退出方式；2014 年 12 月他接到郑宇电话，说今日头条要收购，他当时甚至不知道今日头条，只知道头条 2014 年完成 C 轮 1 亿美元融资。加入后办公室在知春路盈都大厦，楼下有沃尔玛；2015/16 年他第一次意识到字节是一家 AI 驱动公司，今日头条靠推荐算法和神经网络驱动，张一鸣要求员工向亲戚推广产品，而他亲戚 dismiss 某类新闻后仍刷到类似新闻，推荐工程师解释他们也只是“调参工程师”，只能靠实验逼近效果。2015 年字节很 tough，没有抖音，头条 DAU、MAU 留存进入瓶颈，员工流失多；2016 年 12 月做出抖音和火山，到 2017 年境况才改善。

#### 3.2 抖音的意外胜出、火山与百万英雄、50 元获客成本与东京落脚
郭宇说内部并没有把宝全压在抖音上，一鸣一开始想做更大众化的视频推荐产品，大量资源放在火山小视频；火山和抖音的竞争反反复复持续约四五年，最后抖音完成从 18—20 岁到 7—70 岁的用户泛化，火山的历史目标被抖音完成，二者合并。抖音起初团队很小，名字曾叫 A.me 之类，非常小众；并购 Musical.ly 后改名，Alex 加入后产品形态和推荐算法核心引擎显著增强，用户泛化做得很好，最终变成极大众产品，这是一开始没想到的意外。中台时期他支持过视频直播“百万英雄”，项目投放很多钱到 CCTV 年夜饭晚会，用户答题可拿 100 万奖金；之后做 micro-runtime，即跑在抖音和 TikTok 上的小程序引擎，可动态发布 JS bundle，实现广告后实时玩游戏。2019 年字节获客成本高达 50 多元人民币一个新用户，连 retention 很好的“App 工厂”都很难拿新用户，他觉得移动互联网周期基本做完，2019 年底想走，交接半年。2020 年过年回家后去日本旅行，疫情爆发、国际旅行禁止，他无法回北京，电脑交接由同事半年后处理，后来办长期签证到永驻；离开字节因此是机缘巧合，也是疫情改变命运的例子。

#### 3.3 Vibe Coding：从执行者到“全员”，决策负担与 burnout
Vibe Coding 之后，Coding 能力本身被 AI 接管，工程师退位为观察者，第一件事是适应身份角色变化；传统科技行业工程师是执行者，小团队以两周或一周半为迭代周期，做开发、设计、测试、发布和实验观察。现在一到两人的团队半天就能完成一次这样的周期，但事情没有变轻松，因为人要身兼工程师、架构师、设计师和产品经理，最重要的是产品经理角色：要善于提问，找到语言空间，知道用什么语言和模型沟通，知道什么语言结构能让它持续推进实验，并根据 loop 结果调整方向。AI 不能完全自动决策，不仅因为没有上下文，更主要是没有主动意图，所以所有决策仍由人承担，心理负担比过去大很多；2024 年 10 月到 2025 年两三月，许多工程师朋友高强度工作后 burnout，废寝忘食做出以前一两年的事，人类大脑能量低、跟不上 AI 速度，植物性神经焦虑。最近 Claude Code 已决定取消[[002_f3ll98pj|计划模式]]，因为 loop 或 agentic coding 足够强，可以提前聊半小时、把所有 spec 计划详细，然后一次性跑目标，也可以 24×7 运行；郭宇最近半年已很少使用计划模式。主持人补充，不讨论实施方案会缺少掌控感，有些 business 逻辑仍要清楚，他会让 AI 做完后解释怎么想、为什么这样做，相当于让 AI 教自己；郭宇则说自己放手更多。

#### 3.4 软件不再是写死代码，Agent OS 与远程计算资源
软件本身已不再是写死的代码，SOTA 模型可以很快编码 web app 或 iOS app，做成固定范式和流程给别人用，但软件形态变成即时生成、为完成任务、用完可丢、或只给自己使用。东旭在 1 月或 2 月已控制几百个不同虚拟机连续跑一整晚，一天消耗约几十亿 token，认为可以通过矩阵式 agent 网络做任何软件；郭宇由此理解，过去 AI 推荐引擎把做好的软件内容面向所有人个性化，现在连软件本身都可以完全 customize，每个人的软件不同，也无需兼容。First-class Harness 如 Claude Code、Codex/ChatGPT、DeepSeek Harness（DSH）由 SOTA 模型工厂或实验室推出，把很多软件功能内化，做 CRM、管理系统只要两分钟、五分钟、十分钟，特化软件的 distribution 或分发已失去意义。[[011_6ac6dabe|Agent OS]] 的思路是基于 Linux，把 Agent 当作 first class，而不是把 application 当作 first class；OpenAI 走另一条路，买了很多 Mac，让下一代即 4o 模型操作 Mac，因为 Mac 是成熟 Unix 发行版，创意、电影制作工具成熟。未来手机连接的可能是远程 Mac、家里 Mac 或东京服务器，计算资源会变成 virtual agent server；Grok-bot 已有 Agent OS 感，云端电脑总协调，MacBook 和 Mac mini 可共享数据，用户说装 Node 就自动装好，Codex 从 2 月起支持远程 SSH 和 WebSocket 穿透内网。这也带来安全隐患：若 OpenAI 被攻击或连接被劫持，可能变成世界最大肉鸡集群，通过 agent 操作数十万甚至上百万计算资源。

#### 3.5 智能的五类分层、2% Pro User 与智能商品化
郭宇把智能或模型应用分成五类：个人便利型，如 Facebook/Meta Muse，集成 Messenger、Instagram、WhatsApp，只对美国开放，完成订餐馆、旅行预订、信息管理，不需要特化软件；郭宇 3、4 月做过打电话测试，Tuwa 和 OneMan 想让 agent 自动管理电话、邮件和信息沟通，发布后一直有欧洲用户用葡萄牙语、西班牙语。第二类是个人生产力型，如 Claude、Codex，用于写代码、创作；第三类是企业生产力协作，微软把 Copilot 变成 Operating System，让 Agent 操作 Office，但大企业尤其日本企业顾虑没人负责，中层不敢用 DeepSeek，担心信息被蒸馏。第四类是娱乐生成，字节 C-Dance 配合红果形成 AI 生成、人类消费短剧的闭环，BytePlus 做面向海外创作者的工具，字节和 Meta 因 Metaverse、社交平台和消息流在互动游戏、元宇宙上占优势；第五类是科研探索，最牛模型不会公开，可能与研究所、药企签年度框架、利润分成，国防订单也类似。大众并不需要最强模型，只需要最合适的模型；前两年追 SOTA，现在分层为最先进科研、SOTA 创造、便宜快速解决个人需求、更便宜 DeepSeek 做现场 AI 和边缘计算，比如牧场识别牛是否跑出栏，不可能把所有图片传给 OpenAI。当前 AI 对人类社会、组织结构、商业的影响仍非常早期，投资视角只完成 2%、3%；只有 2%—3% 的人成为 Pro User，把 Pro User 放大十倍，一个人管上百台 Agent Server，等于之前五六十人公司规模。普通人最多把 Gemini、ChatGPT 当搜索引擎，大量人需要生成式娱乐填补时间；智能会商品化，像牛奶一样便宜，完全竞争市场定价趋近成本，可能变成 Public Goods。

#### 3.6 Everything is Media、AI Slop、真人感与文艺复兴
郭宇重心从创造软件转向创造软件要达到的目的，但一度迷茫；尤雨溪把创业公司卖给 Cloudflare 后也 burnout，思考下一阶段；他回忆字节 2012 年建立后用两年验证推荐系统在文字、图片推荐上的效果，等到 2015 年 3 月冲绳年会讨论手机流量看视频的环境成熟，视频推荐才进入成熟领域。现在如果环境不成熟、用户不知道怎样使用产品，还按十几年前创业思路做软件、分发给用户，本身意义不大。主持人说提供“活人感”重要，人与人的情感连接在 AI 智能化越来越发达时会越来越强；郭宇想把 attention 产品化，让别人进入像社群的地方，让他的 Agent 整理内容，再由别人的 Agent 读取，完成信息传递，交付 attention，软件变成媒体，Everything is Media。Zora Zhang 说初创公司 Demo 要真人出镜介绍产品，因为 AI Slop 让信噪比极低，真人内容差异化；过去自媒体也 hack 推荐算法，如视频字幕加错别字提高完播率，字节有团队抵抗 hack，但算法工程师也只是调参，无法干预内在运行逻辑。娱乐产品竞争用户时间直接，抖音抢腾讯游戏份额，长视频也一样；若目的是消耗时间，中间软件形态不重要。日本平成废宅、Arubaito 临时工、做三休四、九十九里滨冲浪、滑板选手参加奥运，说明物质丰富后兴趣导向；抖音既可是信息茧房也可是窗户，偏远西部山村小孩用塑料破布做衣服走秀，最终去米兰走秀。

#### 3.7 给年轻人的建议：别守下跌的股票，工作不是必选项
郭宇说现在年轻人有两类明显 concern：一类很焦虑，觉得很快失业或根本找不到工作，因为 AI 降本增效让企业 opening jobs 变少；另一类小孩对 AI 感兴趣，能做以前不能做的玩具和游戏。被迫找工作的阶段只能不断调整目标，最重要的是不要把工作视为人生保底、金饭碗或必须选项；若不工作，面向的选择是无限的，短期会放大焦虑，但长期可避免下滑。他用股票类比：被套牢时要看有没有更好机会，以及是否处在非常长下坡的雪道；他父亲在国营单位或集体场子里工作，去南方时每月花几百块停薪留职，怕工龄消失，但矿山几年后倒闭，东北下岗工人印象更深。若去前沿 AI 工作室、成为创造者，工作还值得做；但去沉闷单位、把铁饭碗当目标，或盲目考研，没必要。南方小孩对赚钱更敏锐，广州、潮汕家族从小经商，深圳有意思；他潮汕室友在 2011、2010 年就说家族观念是宁做小老板也不打工，打工永无出头之日，这个想法放在 AI 时代很受用，建议去深圳看，做自己的老板、One Person Company。

### 4. 核心观点与论证
1. 软件成本趋零并即时生成，会瓦解传统软件分发。论据是 First-class Harness 已把 CRM、管理系统等需求内化，特化软件的分发失去意义，软件可完全 customize、用完即丢；因此真正要交付的是目标、体验、attention 或媒体，而不是软件本身。
2. Vibe Coding 不减少工作，而是压缩执行、放大决策。论据是半天可替代过去两周迭代，但人要同时做工程师、架构师、设计师和产品经理，AI 又没有主动意图，所有决策仍由人承担，导致高强度决策和 burnout。
3. Agent OS 将成为下一代操作系统形态。论据是基于 Linux 把 Agent 当 first class，OpenAI 买 Mac 让 4o 模型操作，Grok-bot 已能云端协调 MacBook 和 Mac mini，Codex 支持远程 SSH 与 WebSocket；但这也可能形成世界最大肉鸡集群。
4. 智能会分层并商品化。论据是个人便利、个人生产力、企业协作、娱乐生成、科研探索五类模型各有场景，2%—3% 的人成为 Pro User；完全竞争市场会让智能定价趋近成本，像牛奶一样便宜，甚至成为 Public Goods。
5. Everything is Media：软件媒体化，真人感和情感连接更稀缺。论据是 AI Slop 使信噪比极低，Zora Zhang 建议真人出镜，错别字 hack 完播率，娱乐产品直接竞争用户时间；郭宇因此想交付 attention，让社群和 Agent 网络完成信息传递。
6. 工作不再是必选项，年轻人不应守下跌的股票。论据是上班从工业革命开始仅百余年，智能革命后可能消失；日本 Arubaito、做三休四、潮汕宁做小老板不打工、深圳商业文化都说明，转向兴趣、创造和 One Person Company 比守住铁饭碗更符合 AI 时代。

- 奥运滑板选手很多不是专业运动员，而是长期兴趣积累后参赛。
- 抖音字幕加错别字会提高完播率，字节有团队抵抗 hack 推荐算法。
- Zora Zhang 说初创公司 Demo 要真人出镜。
- 郭宇父亲去南方时每月花几百块停薪留职，怕工龄消失，后来矿山几年后倒闭。
- 郭宇潮汕室友在 2011、2010 年说家族观念是宁做小老板也不打工。

### 6. 金句
1. “那未来我们获得任何的软件，它的成本都会变得像牛奶一样便宜。”——在讨论智能商品化、软件边际成本趋零、完全竞争市场定价趋近成本时，郭宇用它概括软件获得成本的变化。
2. “你工程师退位为一个观察者之后，第一件事情要适应是整个身份角色的变化。”——郭宇谈 Vibe Coding 后工程师从执行者变成观察者，必须重新适应产品经理、架构师、设计师等多重角色。
3. “写代码这件事情就变成了一个更复杂的一个脑力活动，而不是以前这么简单的一个脑力活动。”——在说明半天可替代两周迭代、但决策负担更重时，郭宇强调 Vibe Coding 没有让脑力活动变轻松。
4. “软件本身已经不是写死的代码了。”——郭宇谈软件即时生成、用完即丢、每个人软件都可完全不同且无需兼容时，用这句话概括软件形态的根本变化。
5. “上班这个事情从工业革命开始，在智能革命之后消失。”——在讨论工作是否仍是必选项、日本 Arubaito 和兴趣导向生活时，郭宇把“上班”放进工业革命到智能革命的历史尺度中。
6. “打工永无出头之日。”——郭宇引用潮汕室友家族观念，说明宁做小老板也不打工，并认为这个想法放在 AI 时代很受用，建议年轻人做自己的 One Person Company。

### 7. 延伸思考
1. 当软件像牛奶一样便宜、即时生成、用完即丢，价值捕获点会转移到哪里？是 attention、社区、信任、审美、问题定义能力，还是像郭宇说的“交付目标”和“媒体化”的个人品牌？这需要重新理解产品、公司和[[010_6aba599d|商业模式]]。
2. Agent OS 和远程控制普及后，安全、责任与企业采用如何解决？郭宇提到 OpenAI 若被攻击可能成为世界最大肉鸡集群，日本企业又因“没人可以负责”而迟疑；当 Agent 操作数十万计算资源，谁为决策和事故负责？
3. 当工作不再是必选项、上班可能在智能革命后消失，教育、分配和人生意义如何重构？日本平成废宅、Arubaito、做三休四是一种样本，但大众娱乐消耗时间与少数 Pro User 创造爆发之间的分化，会怎样影响社会结构？

### 8. 结尾一句话点评
这期对谈最有价值之处，不是给出 Agent 时代的确定答案，而是把“软件像牛奶一样便宜”后的真正问题推到台前：当执行被 AI 接管，人要交付的也许不再是代码，而是意图、判断、attention 与活人感。
