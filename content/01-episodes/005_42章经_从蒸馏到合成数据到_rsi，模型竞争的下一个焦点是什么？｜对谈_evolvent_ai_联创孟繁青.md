### 1. 一句话概括
本期播客对谈 Evolvent AI 联合创始人孟繁青，从他离开 Kimi [[001_42章经_ai_发展了_4_年，把应用发展没了？｜ai_年中复盘|创业]]的亲身经历出发，深入梳理了后训练、合成数据、蒸馏与 RSI（递归自我改进）等当前 AI 领域最热议题，并提出了一个核心非共识：国内模型真正的竞争优势不在偏工程的 Post-training，而在被资源限制倒逼出来的 **Pre-training 架构创新**。

### 2. 节目信息（主播/嘉宾/节目背景，如能从内容判断）
- **主播/主持人**：曲凯，42章经创始人。
- **嘉宾**：孟繁青（51号珍藏），Evolvent AI 联合创始人；NUS PhD（01 年出生）；前 Kimi AI Lab 实习生，focus 在 RL Infra，参与 **Kimi K2.5、Kimi Linear** 等重要模型发版。
- **节目背景**：42章经近期与多位模型和算法从业者交流，发现数据的重要性再次凸显，尤其在合成数据公司快速创收和模型厂、大厂加大数据投入的背景下，邀请较早抓住合成数据机会的创业者进行系统性梳理。
- **参考消息**：8 月 22 日会有繁青参与的线上活动。

### 3. 章节要点（按话题分段，每段 4-6 句，包含具体细节与论证）

**3.1 大厂 vs 创业：训练基模是工程，创业要做正交切入点**
孟繁青回顾了从 Kimi 到创业的感受：在大厂训练基础模型已被高度工程化，内部训练和推理流程非常稳定，研究员只需提交请求即可完成 SFT。出来创业后，他们没有资源去训基模，因此需要找到与模型厂“正交”的切入点（如平台类 Infra、RSI 方向），而非直接推进模型智力本身。这也解释了为什么 Post-training 背景的人更容易创业：因为 Post-training 往往做的是合成数据和 Bench，离落地应用和商业场景更近；而 Pre-training 的人每天打交道的是模型架构和优化器，极其吃资源，初创公司难以覆盖成本。

**3.2 Bench 的演化：从“做题”到“模拟工作环境”**
孟繁青用“白领日常工作”比喻解释现在 Bench 的区别：过去测的是模型“大脑”，直接回答一道难题即可（类比数学考试）；现在则需要模型在一个模拟真实软件（如[[004_苔藓之火_办公agent大战：为什么大厂做不出好ai产品？-_马克汤|飞书、Notion]]）的环境中与工具交互，考验“动手能力”。这种环境型 Bench 的难点在于：一方面要确保环境与真实世界 align（输入相同则输出一致），另一方面评分机制非常复杂，需要拆成多个细小的得分点，而不能简单判断对错。目前这些评分仍高度依赖人的精细设计，或者“人跟 Agent 一起去 check”。

**3.3 Post-training 门槛降低与数据质量的核心地位**
模型厂内部已将训模型做成“提交请求即可”的服务，因此 Post-training 的门槛对大多数 researcher 来说确实降低了（但 Infra 侧仍有坑）。然而这并不意味着枯燥：造数据的难度和差异性很大，核心 know-how 难以被 Agent 替代。孟繁青团队在 RSIBench 中发现，Agent 完成机械化修改（如修复格式错误）还行，但无法提出造数据的“insight”。数据质量的好坏最终只能通过“在 Bench 上能否真正提高”来验证，且当前合成数据与真实场景的差距、数据难度的适中度，都会直接影响最终效果。

**3.4 国内 vs 海外模型的真正差距：Pre-training 反成优势**
孟繁青提出了一个反直觉的判断：国内模型与海外模型的差距在缩小，且国内真正的特色在 **Pre-training（架构创新）** 而非 Post-training。原因在于：Kimi（Linear 注意力机制）和 DeepSeek（Multi-latent Attention）在[[003_101_weekly_杠杆、垄断和泡沫：解析硅谷万亿资本闭环｜20251014|有限资源]]（约海外十分之一的卡）下，被倒逼出了省计算量的底层架构创新，且已被证明具备 scale 能力（如 K3 已接近 Fable 的水平）；而 Mamba 这类海外架构反而未被验证。反观 Post-training，国外在数据积淀上天然早半年，且数据积淀是偏组织架构和人力的事，更难靠个人聪明才智弥补。

**3.5 国内模型竞争格局：交替领先是常态**
国内模型商的竞争基本是“某一家发大版本模型后成为开源社区 Top 1/Top 2，几个月后另一家超越”的交替局面。DeepSeek 和 Kimi 靠 Pre-training 架构创新领先，智谱此前靠 Post-training 的 coding 数据做好。模型之间最终比拼的，不仅是卡、数据和架构，更是**[[004_苔藓之火_办公agent大战：为什么大厂做不出好ai产品？-_马克汤|组织架构设计]]**（如多模态是否单独划部门已成为共识，现在大家倾向于将其与 Pre-training 合并），以及数据积淀的工程化能力。

**3.6 RSI、Self-Evolving 与 Auto-Research 的实质**
RSI 通俗解释就是：给模型一个环境和一个目标，让它在里面持续操作、拿反馈、修改操作，最终突破上限。孟繁青认为目前做 RSI 的方法本质上是“更聪明版本的 DFS（深度优先搜索）”，即模型用预训练内化的 World Model 能力去“剪枝”，预判未来状态和收益，避免走死路。因此**不存在“RSI 专用基础模型”**，模型厂在预训练时已经把 RSI 能力内化了；RSI 变强的来源是 World Model 内化得更好以及 context 窗口更长（目前最高 1M）。他认为 RSI 创业公司的机会不在训基模或出 Harness，而在做一些介乎模型厂和应用层之间的“RSI 通道”。

**3.7 数据需求的三代更迭与价格体系**
数据需求经历了三波：第一波是 Scale AI 式的普通人标注（for 预训练 raw data，现在需求已不多）；第二波是 O1 出现后的专家数据（专家不仅要做题，还要出题且与所有公开题不重合，难度极大，需求也在下降）；第三波是合成数据（for Agent，需要造环境让模型探索并保存轨迹）。合成数据一条“长程任务”可卖到几千元，专家做题数据约一两千元一条，真人操作轨迹则更多是走量。合成数据单子未来会变少，因为 Bench 数量在收敛，模型厂可以自己 focus 在少量头部 Bench 上造数据。

**3.8 合成数据与蒸馏：有技巧的蒸馏才有价值**
合成数据与蒸馏常被绑定，但关键在于“硬蒸还是技巧蒸”：硬蒸相当于环境太简单（如普通数学题直接抄答案）；有技巧的蒸则要求环境足够复杂、题目和评分正确且高质量，这样即使是最先进的模型，自己在环境里探索并拿正确的轨迹训练自己，也能提炼提升（本质就是 RL）。蒸馏对相对落后的模型价值更高，因为学习的 margin 更大，但对领先模型也有用。关于竞争格局，蒸馏对国内模型追赶起到“加速手段”而非“决定性因素”的作用，因为智力的基础来自预训练。

**3.9 技术路线、AI4S 与初创/大厂的未来**
模型厂当下的状态是：coding 依然是核心基础路线，但 pipeline 相对稳定，于是开始探索 Auto-research（如 AI for Science）作为新的 PR 和智力展示手段（如让模型设计分子结构、蛋白质），这比奥赛级题目更能体现智力上限。孟繁青个人更看好初创公司而非大厂，因为技术本身会在公司之间流动，大家水平差异不会特别大，最终比拼的是“组织形态”——如何让公司作为一个整体跑得更快。模型厂之间的竞争剧烈导致降价（如 GPT 降价 80%），但降价是商业模式考量而非单纯成本降低，若真出现一两家的垄断，价格未必会一直降。

**3.10 Evolvent AI 的未来：数据现金流 + RSI 长期愿景**
Evolvent AI 成立约半年，团队以 00 后 researcher 为主，目前 focus 两块：短期做合成数据（有商单和现金流），长期做 RSI 方向的产品。他们最想做的事不是训练 RSI 专用基模，而是做“桥接模型厂与应用公司”的中间层。最近发布了 **RSIBench-Data**，是数据层面自进化的初步探索：让 Agent 在数据层面自进化，合成更好的数据去迭代小模型。招人方面，他们更看重工程能力而非论文引用等量化指标。

### 4. 核心观点与论证（节目提出的主要论点及论据，3-6 条，每条 2-3 句）
1. **国内模型的优势在 Pre-training 架构创新，而非 Post-training 数据积淀。** 论据是 Kimi Linear、DeepSeek MLA 等架构被证明具备 scale 能力，且是在海外十分之一算力下被迫创新的产出；而国外数据积淀只有时间差和人力问题，属于更难追赶的工程和组织架构问题。
2. **蒸馏只是加速手段，不是决定性因素。** 智力的基础来自预训练，国内模型厂已具备自己的架构创新能力和强大的自研模型，即使封掉所有 Claude API 等蒸馏通道，也可以靠自己模型做合成数据或下狠心搞数据积淀，只是更费劲而已。
3. **不存在“RSI 专用基础模型”，RSI 本质是 World Model + Value Model 的剪枝过程。** 大模型预训练已经内化了这两项能力，RSI 的提升只取决于 World Model 内化程度和 context 窗口长度，所以 RSI 是模型厂已具备的主路径能力，而非新 lab 的专属赛道。
4. **数据行业正从“人力密集”转向“研究驱动型”。** 专家标注公司若只靠人力很难跟上趋势，反而是有一线 researcher 和 know-how 的公司（如 Evolvent AI）能够抓住从 Agent 数据到 RSI 数据的每一波潮流；合成数据单子会减少，但 RSI 轨迹数据将成为下一波昂贵稀缺的中间产物。
5. **工程能力比学术论文更能代表优秀 researcher。** 造数据、训模型的过程是工程驱动的，能把整个 pipeline 跑通并拿到结果的人，比发表大量论文的人更适合当前模型竞争时代。

### 6. 金句（引用原话，带上下文，3-5 条）
1. “蒸馏我认为不是国内模型变强的一个决定性因素。因为智力的基础是来自预训练的，预训练国内是做得比较好的……蒸馏只是国内公司的一个加速手段，也不是说没有 Claude 的 API 它就做不出这个事。”
2. “现在做 RSI 的这些方法本质上都是在做一个更聪明版本的 DFS（深度优先搜索）。它会加入一些剪枝……得靠 World Model 加 Value Model，而大模型预训练本身已经把这两件事给内化了。”
3. “算法就是数据，数据就是 Infra，Infra 就是算法——其实没啥毛病。因为算法会收敛到最简单的形式，而数据是驱动算法和 Infra 更新的源动力。”
4. “我之前以为国内更有优势的是 Post-training，但出来后才意识到，国内模型真正有特色的地方反而是被资源限制倒逼出来的 Pre-training 架构创新。”
5. “一个足够优秀的对 Agent 的 Bench，是工程上实现就会比较好的，相对而言它转成一个可以落地的商业模式也会更简单。”

### 7. 延伸思考（节目引发的值得继续思考的问题，2-3 条）
1. **RSI 如果真的实现，是否意味着基础模型厂商最终成为“极少数人的生意”？** 孟繁青认为从结果上可能如此，但由于组织架构、应用场景和数据隐私等考量，未必会极端到只剩 10-20 人。
2. **数据行业门槛持续提高后，普通个人/小公司是否彻底被排除在外？** 个人用户产生的数据太脏且有合规问题无法出售；但如果未来 Agent 使用量暴涨，真实交互轨迹数据是否可能成为新的稀缺资源？
3. **如果海外真的封死所有蒸馏通道，国内模型的追赶速度会有多大实质性影响？** 孟繁青认为只是更费劲，但这是否意味着国内后训练数据上的短板可以纯粹用人力投入和自研合成数据弥补，值得跟踪验证。

### 8. 结尾一句话点评
从架构创新到数据变现，从蒸馏争议到 RSI 愿景，这期节目系统性地解构了“国内模型靠什么追上”这个核心命题，并给出了一个相对乐观且反主流的判断：真正的护城河从来不是抄近路，而是被倒逼出来的原创架构能力。
