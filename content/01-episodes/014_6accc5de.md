### 1. 一句话概括
42章经曲凯对谈 Ambi 创始人莫子皓，围绕 [[010_6aba599d|Personal Agent]] 的爆发逻辑、成本与需求、交互入口、软硬件结合、A2A 网络效应、创业赚钱与招人经验，以及国内 AI 产品为何缺席展开。

### 2. 节目信息
- 节目：42章经，主播曲凯，42章经创始人。
- 嘉宾：莫子皓（子皓），Ambi 创始人，曾任 Plaud 合伙人兼中国区 CEO；曾创办「米公益」，公司后被轻松筹收购；此后任暖哇科技合伙人兼首席产品官、百川智能医疗方向产品及运营负责人。
- 背景：Ambi 做 Personal Agent 软硬件结合产品约 6 个月，节目在国庆前录制，2026-10-12 发布，时长 5178 秒。
- Ambi 最近开放下载，App Store 可下但需邀请码；42章经拿到 5 个邀请码，供听众填表申请。
- 节目主线：Personal Agent 这波火是否有迹可循、成本多高、需求多大、产品路线怎么选、面对大厂怎么竞争，以及子皓个人为什么擅长 deliver 结果和赚钱。

### 3. 章节要点

#### 3.1 Personal Agent 为什么火：OpenClaw、Hermes、Muse 的主线
曲凯认为 Personal Agent 是 OpenClaw 的延续，而 OpenClaw 又是 Manus 以及 2023 年以来「用 AI 做事情」这条线的延续，Agent 和 AI coding 也在合流。子皓不觉得 OpenClaw 是乍现，因为 Muse、Grok Bot 这类产品已经具备让普通人使用的所有要点：不需要技术背景，甚至不需要知道背后有虚拟机。他拿 Muse 举例，认为它像上一代移动互联网产品一样容易上手；同时 Business Insider 报道 Muse 时，扎克伯格、GitHub 前 CEO Nat Friedman 都惊讶为什么是 Muse 第一个发，而不是其他大厂。子皓自己从年初到现在一直用 OpenClaw、Hermes、Codex 跑工作、生活、健康等定时任务和主动服务，因此不认为这事已经不火，只是当时还没到 C 端 PMF。核心卡点不在技术，而在产品与传播链路：OpenClaw 安装成本高，装完还要接 connector、加 context，很难把「厉害」瞬间分享给别人。

#### 3.2 智能足够了吗：去年可能想错了，模型升级带来巨大变化
曲凯回忆去年两人聊过「智能已经足够了」，子皓现在认为可能说错了：不是智能足够，而是当时设计的任务不够复杂、给模型的 context 不够多、来源不够丰富，所以误判了上限。聊天场景里[[011_6ac6dabe|开源模型]]可能已足够，但工作场景里，每次模型升级都要先剪 harness、剪 system prompt，让它适配新模型，再跑同样任务，能感受到巨大提升。子皓举例，公司把 Lark、GitHub、飞书文档、聊天、文件、开会全部放开，让模型处理模糊任务；ChatGPT 6 出来后，同样任务不再长篇大论，写得更少却表达更好、更精确，甚至总结出人自己总结不出的东西。由此他判断人对智能的需求上限很高，还没到无限，但已经是非常 aha 的时刻。对 Computer Use，他认为它处在模型非常直接的链路上，属于「过一会儿模型天然就能做到」的方向，所以 Ambi 把它当基础能力，不自己重做，等模型开放权限后自然使用。

#### 3.3 成本、延迟与需求：成本不是大问题，交互成本才是关键
子皓认为这波 Personal Agent 里，用户并不 care 背后用了什么模型；订餐厅、订票等任务也不是在智能层面体现多高，用户对延迟没那么苛刻。因此成功率、速度、质量之间，速度可以相对放弃一点，成本至少目前不是特别大的问题；Ambi 不愿因成本阉割体验，商业模式上也能成立。需求侧的关键在于：智能是默认触手可及，还是需要花交互成本才能用。如果张嘴就能让 AI 做事，大家会默认智能可以帮自己做任何事；但现在要 setup、要拿出来解释、要跟它说，生活里很多鸡毛蒜皮、ROI 不清的事情就不会触发。子皓用「电量焦虑」和「增程汽车」类比：可能一百天不用一次，但一旦需要就很痛；如果 24 小时随时随地获取智能的成本很低，人就会用。公司有人自驾去新疆，突然要改宾馆、找最近加油站、找修车厂问价格，这种特殊时刻需求很强；所以不能把工作和生活需求简单二分，核心是获取智能的成本会改变需求答案。

#### 3.4 To B、To C、大厂与网络效应：Personal Agent 天然不带网络效应，但 A2A 可能带
曲凯问 Personal Agent 竞争是否最终就是 ChatGPT、Claude，子皓认为最终会走到一起：生活场景一定和名、利相关，能找到明确 ROI 的切入点，大厂都会做。对于 [[009_6a942381|Coworker]] 路线，子皓认为不是唯一解，不同组织形态都可能成功，像桥水全员透明也能 work；Coworker 发展没想象中快，是因为组织变革会被「水管最窄的一段」限制。电发明后按用电方式建工厂可能要 30 年，coding agent 出现后新建公司也要时间，才会完成社会淘汰和换血；新公司效率更高、人才密度更高、知识有复利，长期会取代旧公司。曲凯问 To C 是否赢家通吃，子皓认为如果获客依赖强网络效应的上游，就很难独立成为巨无霸；《颠覆式创新》之后，渠道和分发比产品本身更限制新巨头。子皓说 Personal Agent 名字天然不带网络效应，但 A2A 可能带：不是因为能 A2A 才有产品，而是因为用了产品才有 A2A；用户有自己的 memory、file system、沉淀，人和人连接需要别人脑中的 knowledge 和时间，agent 之间共享 personal 东西就可能给双方带来正向帮助。他举例 Lark 群里同时有他和他的 permission agent，别人 @ 他的 bot 审稿、看方向，既解决权限，又天然形成 A2A 场景。

#### 3.5 简评 Town、Grok Bot、Muse、Instinct：产品路线与交互体验
Town 子皓认为有 YC 痕迹，CEO 是原 Plaid CTO，特别注重权限和 reference，明确什么时候用 connector、什么时候用权限，因此适合 To B，也切邮件自动打标签、归类、写草稿。但回到工作生活，多少邮件可以不用任何 intention 自动回复？其实很少；Town 最大人群之一是家长，因为学校不断有夏令营、报班、作业等邮件，他们做的 828 很复杂，产品信息架构不如中国团队明确，对智能使用也不高，不在智能延长线上。Grok Bot 子皓评价非常好：授权、透传、稳定虚拟机做得好，接 MCP 或接口接不上时就起浏览器，输邮件密码时弹窗让用户输入，有大厂背书，普通人觉得相对安全；Bot 之间通信和 context share 较好，Cursor 团队和增长负责人做产品，小细节和传播方式好。Muse 有明显上一代移动互联网烙印，非常精细、打磨多、花钱多，每个人上来 1 亿 token；第一天用就觉得不能做一样的事，它像移动互联网时代定义的好产品，Instagram 顶部也在推，容易上手，connector 描述有巧思，goal 功能与 Ambi 设计相似，会往普通人方向比 Grok Bot 走得更远。Instinct 他们没环境用，因为生活在一个有美团的国家，难理解其需求；美国几家宣传订机票、订酒店、订餐馆，其实是解决 OpenClaw「案例难描述、难使用」的问题，用「下 App 不花钱还省 499」这类传播方式，像回到互联网年代，Lovable 建站省 499 也是同一增长路线。

#### 3.6 [[004_6a6b73e9|国内大厂]]、交互难受与应用公司训模型
曲凯唏嘘国内环境不同，否则可能已开始补贴大战，像美团、腾讯、字节都该出东西；子皓认为这一波大厂相比上个时代失去了成为世界第一、领先全世界的雄心，很多只是做「中国的什么什么」，原创好产品很少。子皓说 AI 眼镜每次用都要先唤醒、重复对方说的话、再说要求，这种重复很难受，因为它不是一直在跑；Ambi 半年前出来想解决的就是交互问题，希望 AI 像软件、像空气一样默认围着人跑。对于应用公司自己训模型，子皓认同红杉某合伙人观点：模型公司给的接口是帕累托最优曲线上的几个点，应用公司要在成本、速度、智能上找别的点，不是追求更高智能，而是优化 ROI；所以训模型合理，但说能训一个智能程度更高的模型很荒谬。端侧上 Ambi 不会做端侧大模型，因为现在不是算力限制，更多是电池限制；电池越大越重越厚，影响佩戴和使用，别的放桌上、NAS 场景可能需要，但 Ambi 不做。

#### 3.7 个人经历：timing、赛道、商业本质与硬件认知
子皓第一段经历是做六年公益创业，融了三轮，后被收购，钱也退回去了；最大认知是 timing 和赛道比能力更重要，选择比努力重要，大浪潮比选择更重要。第二段做保险、创新支付、SaaS 四年，让他理解很多商业模式本质，认为商业没有秘密，最底层就是效率、ROI 和需求；当时业务有抖音投放、CPA 投放、大型央国企、外企、外资药企、创新支付，大概六七种商业模式，每种至少做到全国前三、前二。到模型公司、硬件公司后，硬件补齐研发、仓储、硬件设计；硬件和 To B 软件很像，To C 软件要多试错、找到好地方就大步走，To B 交付在签单时收入已 capped，利润来自交付更好、成本更低，硬件也是第一天要去掉后续风险。他认为这很像移动互联网刚开始的时代，历史押韵；自己 2013 年开始创业做 App，赶上移动互联网尾巴，经历大模型后，觉得短期成功在底层技术剧变时代很容易变化，变化足够快、找到核心方式才是唯一竞争力。

#### 3.8 赚钱案例：高三溜冰票独代、轻松筹保险、海南电销
子皓高三毕业想不用脑子、用体力打工，第一天在广州北京路卖溜冰票只卖了约五张，去五月花广场楼下卖英语教育站一天只拉了一个人，第二天就辞职，承认拉不下脸。后来他发现年轻人在溜冰，就去广州兼职网站发招聘，自己 25 元拿票，27 元给代理，代理 30 元卖给同学，赚 10%，成为溜冰场独代；到大三还有人从他这里拿溜冰票，一个月时间所有溜冰场票都他来卖。被轻松筹收购后，他花一个周末一页页看用户怎么买保险、流量来源、user journey、哪里卡住，发现很多基础 tracking 都没建，建立基础分析后一天时间帮业务翻 30%—40%。在海南管电销时，他第一次管电销，发现销售最大点是利益，申请预算，每人 100 面红旗，出一单敲锣插旗，最后多少面红旗换多少钱，那个月利润翻 200% 多。创新支付业务中，竞对一家独大，药企担心安全问题，他给的选择是「跟我合作一定清白」，找到决策者根本驱动力，而不是只比价格。

#### 3.9 招人：真诚、分享、花时间、快速 move on
子皓总结招人首先是真诚，第二是积累和愿不愿意真的分享；成熟的人能分辨真话假话，面对比自己厉害的人没法撒谎，所以要把最真实想法、愿景、过程性奖励讲清楚。他认为真正有才华的人不缺工作，越来越像国外，很多员工来 Ambi 前是收入很好的 freelancer，转全职核心是给一个做更伟大事情的动机。招人没有捷径，要真的花时间：他在海南招电销负责人时，在对方楼下小卖部等了五六个小时，吃了几个清补凉才见一面，最终说服加入。还有一点是快速 move on：聊的过程中只要有一点不舒服，就千万不要推进，因为不舒服最终会放大；家庭背景、决策、对未来判断都可能让人不适合陪你很久。

#### 3.10 最近思考：速度、一年做三年、硬件优势与交互机会
子皓最近思考 timing：以前好的东西要花三年做，现在写代码原来三年、三十个人才能做的事，一年甚至几个月可能就能做；但他不认为会极化到「one piece」，Ambi 十几个人很努力才做到现在。他从根本想企业发展，比如硬件 go-to-market 原来先 Kickstarter、找媒体、独立站、亚马逊、go global，为什么要走三年；能不能用 coding agent 改变 coding 的方法，反过来重构业务构成、组织形态和完成方式。很多方法已经跟以前不一样，一年希望做别人三年做的事；如果只是 coding 快，一定不是 Ambi 现在的状态。最担心的是速度，因为速度取决于自己，也取决于别人；苹果设计师去 Meta 后十个月做出 Threads，很难想象，但世界在把一切逼快。好多人好不容易等到一个「有意义的卷」的时代，相比 2022 年那种像死水一样的状态，他更愿意要今天这种焦虑但有变化的状态。

#### 3.11 硬件优势与 Personal Agent 最大机会：线下 context 和交互入口
子皓认为硬件优势有几点：获客渠道本身不具备特别强网络效应，但渠道建立后可成为优势，Anker、大疆、Insta360 的渠道就是优势一环；硬件有独占性，同一时刻你只会带一个东西，而电脑右上角可能跑五个软件，所以 AI 时代附加消费值会被放得高。硬件和软件相反：软件 100 个功能只用 1 个，100 分钟里 98 分钟好用、2 分钟难用可以容忍，因为能换别的软件拼起来；硬件同一位置同一时刻只能搞一个，每天 100 分钟有 2 分钟恶心就是 100% 吃 2 分钟屎，所以必须满足高频刚需场景。硬件劣势是慢、要迭代、讲品味，但盈亏同源；模型卷死一切时，硬件生存空间更大，把两边优势结合可能最优。即便苹果也不是垄断，GoPro 这么差也没倒闭，软件公司可能早没了；深圳戳 demo 很厉害，但稳定大规模交付和高集成度对硬件是 100 倍差别，真正大规模走向市场、做苹果级东西，要动用资本和能力完全不同。子皓认为 Personal Agent 最大机会是交互，人跟 AI 最好想象就是「言出法随」：张嘴说它就做好；一个是好张嘴说，一个是能做好，依赖底层技术。当行为成本变成零，需求会极大放大；Computer Use、Memory 这些技术概念两个月后会理所当然，最终最重要的是人到底怎么用 AI。

#### 3.12 Proactive、工作生活、亿万级 timing 与国内 AI 产品缺席
子皓认为很多产品 Proactive 做错了：现在产品主动性来源是接很多 connector、定时扫、推测给你 aha，但推出来要花成本，智能越高成本越高；推来时用户场景和信息是否匹配、是否觉得被打扰，存在错配，漏斗最后只剩少数 aha，很难算付费和留存账。像秘书每半小时敲门问「要不要看餐厅、分析邮件差异」，一天进来 20 次只为一次好，很奇怪；Ambi 不做这种，主动性来源于环境变化，基于 delta 触发，而不是主动积极扫。工作和生活子皓认为绝对没有差异，应该一体，因为工作和生活 context 能让 AI 更了解你；区分对智能不麻烦，更多是信息架构问题。人格化、头像、名字是一条路线，但 Ambi 不选，天然没有 persona；他们选择 AI 是你的延伸、主体的一部分，而不是不相关客体。曲凯问 Manus、Plaud 等约几十万付费用户，Muse、Grok Bot、WorkBuddy、豆包在冲亿万级平民市场，创业公司该选哪条；子皓选后者，认为前者后者难度一样，后者只是 timing 没到。他判断现在到了能跑出亿万级用户产品的 timing：半年后所有能被数字化的任务成功率默认 100%，Computer Use、Browser Use、长程任务、智能都足够，水电煤基建特别好，上面可以做五花八门东西；成本继续掉，To C 日常任务全可虚拟化完成。最后两人提到今年寒冬，子皓说这么多年没见过像今年一样寒冬，不只是融资，而是可用的中国人做的好产品，无论大厂还是创业公司都几乎没有；Manus、Monica 投资人 Old Friendship 骂国内 VC 不投应用，但曲凯也认为应用确实挑不出几个行的。他们讨论老投资人半退休、离 AI 远、机会主义者创业、模型吃掉应用等问题，但子皓说模型也没吃掉啥；美国不断有人拿到融资，Harvey 估值 100 多亿美金，Town、Instinct 算好产品，Granola 很一般，但中国人做得比 Granola 好的产品都没有。节目最后留了开放问题：为什么国内跑出来的 AI 产品这么少？他们没得出答案。

### 4. 核心观点与论证
1. Personal Agent 这波火不是纯概念乍现，而是模型能力、产品易用性和传播链路共同逼近 C 端 PMF；OpenClaw 虽然厉害，但安装、connector、context 门槛太高，Muse、Grok Bot 这类产品把「普通人可用」做出来了。  
2. 「智能已经足够」可能是误判，真正不足的是任务复杂度、context 丰富度和交互方式；每次模型升级，比如到 5.6、6，在同样工作场景里都能带来巨大变化。  
3. 成本不是这波 Personal Agent 的核心矛盾，延迟也可在多数任务中被放弃；更底层的是获取智能的交互成本，只有接近「言出法随」，生活场景需求才会被极大放大。  
4. Personal Agent 天然不带网络效应，但 A2A 可能带：agent 之间共享 memory、file system 和个人沉淀，人和人连接需要别人的 knowledge 和时间，这种协作会给双方带来正收益。  
5. 大厂一定会做 Personal Agent，国内尤其可能是腾讯、字节等；创业公司的机会在交互、线下 context、硬件入口、持续在场，以及不同于 human-in-the-loop 的主动性和主体延伸。  
6. 商业本质是识别需求并找到交付方式，招人靠真诚、分享和花时间；短期成功在技术剧变时代容易变化，速度、一年做三年、少犯单向门错误，才是创业公司竞争力。

- 成本判断：用户不 care 背后模型；订餐厅、订票不在智能层面；延迟可放弃；成功率、速度、质量 trade-off。
- 需求案例：国庆、中秋非工作场景很少用 AI；自驾新疆突然要改宾馆、找加油站、找修车厂。
- 大厂：OpenAI 马上出类似虚拟机 Bot；字节中秋加班六天搞出类似东西；国内可能腾讯、字节；美团、腾讯、字节若在好时候可能补贴大战。
- 网络效应：A2A 可行；Lark 群里 @ 子皓的 permission bot 审稿、看方向，形成权限与 A2A 场景。
- 组织案例：桥水全员无隐私也 work；电发明后按用电方式建工厂可能要 30 年；新 coding agent 公司需时间成长为巨无霸。
- 硬件优势：Anker、大疆、Insta360 渠道优势；GoPro 差也没倒闭；苹果也不是垄断；深圳戳 demo 强，但大规模交付和高集成度差 100 倍。
- 软件硬件差异：软件 100 个功能只用 1 个，100 分钟里 98 分钟好用、2 分钟难用可容忍；硬件同一时刻只能一个，2 分钟恶心就是每天 100% 吃 2 分钟屎。
- 端侧模型：Ambi 不做端侧大模型，因为电池限制，电池越大越重越厚，影响佩戴。
- 应用训模型：模型公司接口是帕累托最优曲线上的点；应用公司应在成本、速度、智能上找别的点，不是追求更高智能。

- 创新支付：竞对一家独大，药企担心安全问题；子皓给「跟我合作一定清白」的选项，找到决策者安全需求。

### 6. 金句
1. “智能是足够了，在于说是我们设计的任务不够复杂，和我们给它的 context 其实并不够多和来源不够丰富。”——子皓解释为什么去年说「智能已经足够」可能错了。  
2. “大家看硅谷看多了，这个魔怔了一样。就回到十年前或者十三年前，能做 To C 谁做 To B 啊？”——曲凯和子皓讨论为什么大家一窝蜂看 To B，子皓认为能做 To C 就应该做 To C。  
3. “我们跟他们完全不一样的一个定位的点在于说是，就我们在现在的 Personal Agent 的这个状况下，增加了线下的 context 和最重要最重要的一点是，线下的交互入口。”——子皓解释 Ambi 与 Muse、Grok Bot 等纯软产品的差异化。  
4. “软件在跑的时候你根本不用关心它在不在跑，它会不会跑错，你知道它天然就是在跑，它是对的。AI 跟你的关系就应该是这样子。”——子皓讨论 AI 应持续在场，而不是每次唤醒、重复、再下指令。  
5. “水无定势。成功的模式真的是各有各样的，绝对不是只有一种方法。而且更多的点在于说是因地制宜的。”——子皓总结商业经验，后面补充「去有鱼的地方抓鱼」。  

### 7. 延伸思考
1. 如果半年后所有能被数字化的任务成功率默认接近 100%，Personal Agent 的竞争是否会从模型能力彻底转向交互、线下 context、A2A 网络效应和渠道分发？创业公司要在这几个维度里建立什么不可逆优势？  
2. 「言出法随」和「持续在场」需要 AI 一直听、一直看、一直在后台运行，隐私如何被用户接受？苹果式本地 ASR、可信第三方云端、生物识别和可追溯隐私，是否会成为 Personal Agent 的默认基础设施？  
3. 国内今年为什么几乎跑不出让人眼前一亮的 AI 产品？是 VC 不投应用、创业者机会主义、大厂失去雄心、模型吃掉应用，还是寒冬与 timing 错配？如果亿万级用户产品的 timing 已到，什么样的中国团队能抓住？

### 8. 结尾一句话点评
这期播客最有价值的地方，不是给 Personal Agent 下定义，而是把「交互成本、线下 context、A2A 网络效应、硬件独占性和一年做三年」这些创业判断，放在子皓连续创业、赚钱、招人和做产品的具体经验里讲透了。
