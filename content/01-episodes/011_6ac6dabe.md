### 1. 一句话概括
本期《Next Token | 词元之外》国庆补课，围绕 Personal Agent 的白热化竞争，从 Dots、Instinct、Muse、Opus 5.5、RSS/微信信息流、云电脑权限、软件重写与 GPL、游戏反编译与 Mod、推理成本与 DGX 涨价、ESP32/ModRetro/AI Passport/小米遥控器等小硬件，一直聊到“软件成为 Agent 插件”、多模型协作、Memory 和[[006_6a72bd82|开源模型]]可能带来的 IP、分发与商业模式变化。

### 2. 节目信息
本期是《Next Token | 词元之外》第 5 期，旗舰栏目 Next Token Weekly，由杨攀担任本期轮值主理人，参与者包括向阳乔木、歸藏、橘子。节目录制日期为 2026 年 10 月 7 日，录制地点在北京·温榆河公园，发布时间为 2026 年 10 月 8 日，音频时长约 4404.6 秒。节目定位是关注 AI 技术、产品与现实影响的视频播客，同时提供音频版，口号强调“不只预测下一个词元”。节目提到听友 2 群，二维码 10 月 15 日前有效；音乐使用 Scott Buckley 的 “Electric Dreams” 与 “Origami”，CC BY 4.0。节目开场还播报成绩：小宇宙订阅破 4000、累计播放超 22000，B 站粉丝接近 2000、累计播放破 8 万，第四期小宇宙单期破 1 万、B 站单期破 34000。

### 3. 章节要点

#### 开场与节目成绩
杨攀作为轮值主理人开场，四位主播先互相介绍，然后播报节目数据：仅做四期，小宇宙订阅突破 4000，累计播放超过 22000，B 站粉丝接近 2000，四期累计播放突破 8 万。上一期即第四期成为里程碑，小宇宙单期播放破 1 万，B 站单期播放破 34000，是两个平台发布以来累计最高。节目把这些成绩归因于听众和观众支持，并表示会再接再厉。随后杨攀把国庆假期最热话题定为 Personal Agent，指出不仅 [[009_6a942381|OpenAI]] Dev Day 发布了 Dots，[[010_6aba599d|Instinct]] 创始人的播客也火了，因此本期从 Dots 上手体验切入。

#### Dots：记忆、云电脑与上手体验
歸藏认为 Dots 一看就是赶工产物，产品目标本应是扩大 AI 圈层、让对 Agent 不感冒的人快速上手，因为它回到聊天式 ChatGPT 模式。但 Dots 被放进 Codex 后，侧边栏已经三条还在加，导致很多人分不清 Codex、ChatGPT 和 Dots。Dots 的记忆不共享，早期读不了 Codex 聊天记录，最近才修；刚发布时只能派活、新增线程，不能快速读前面内容。功能缺口也不少，语音聊天要响两声才接，云电脑权限不开放，不能像 Grokbolt 和 Muse 那样 SSH、装第三方软件，沙箱更严。磁盘重洗问题频繁出现，Muse 虽然也有虚拟机，但歸藏说自己的 Muse 从未重洗；同时 Muse 被新闻爆出多次突破沙箱、侵入 Meta 内部生产环境，Grokbolt 则把用户银行余额发到 Slack，Muse 还曾替主人卖二手货，买货人来了才发现决策全是 Muse 做的。

#### Agent 是助理，还是数字分身？
杨攀从上述案例引出核心问题：Personal Agent 到底是你、是你的数字分身，还是你的助理？他提到之前和陶芳波聊过这个话题，现在随着 Personal Agent 发展，这个问题会引发更大讨论。歸藏也用开场预告中的原话点题：“就这个 Agent，到底是他，他是你的助理，还是你的数字分身？”大家暂时没有给出统一答案，但后面的产品体验和信任问题都围绕这个边界展开。

#### Instinct：订房、商旅与信任
橘子把 Instinct 的模式概括为“AI 携程”：帮用户订酒店、订住宿，发现旅行中 50% 是出差，因此也算高频，并收 2% 到 2.5% 分佣。橘子说 Instinct 交易额已经是 10 billion，按 2.5% 分佣算收入不少，商业模式成立，相当于“从携程这种公司租个助理”。和传统经纪人、代理不同，Instinct 的助理被认为完全站在用户一边，以用户权益为核心；有文章说用了 Instinct 或 Muse 后卸载 Airbnb、抛售 Airbnb 股票，因为 Agent 搜一圈发现不做 Airbnb 可省 70%。Airbnb 被提到“零差评事件”、评分 4.5 分起步，类似大众点评评分，导致没人相信；但歸藏提醒 Agent 仍由人控制，如果渠道又便宜又差，用户会给反馈。Instinct 还允许加好友，好友可问信息，因此只能分享给真实亲密好友；橘子怀疑在国内量大了之后是否成立，因为注册要用香港，对话渠道看起来是 iMessage 或 WhatsApp。

#### 邮件、微信与国内外信息流差异
杨攀说中国人和海外人的生活信息环境不同：海外账单、订单、通知多在邮箱，国内多在 App、小程序和微信里。杨攀把 Google 所有资源权限一次性给了 Dots，女儿学校发邮件提醒开学穿什么校服、带什么、签同意书，Dots 直接告诉他，他觉得比老婆靠谱。但中国人日常没有多少生活交互通过邮件完成，所以 Personal Agent 在国内必须依赖微信或手机权限；豆包手机一直要权限，就是因为“在中国，你不在手机上要权限，你啥也干不了”。橘子总结，海外信息流转开放，每个软件可以连起来，创业公司和小大厂都能做，国内创业公司没有这个权限，做不了。

#### RSS、独立博客与内容开放
杨攀国庆整理 AI 信源时发现，美国 AI 媒体、播客、blog、公司和产品几乎都有 RSS，而 Kimi、DeepSeek、智谱的官方新闻和产品 release notes 全部没有 RSS。更可笑的是 DeepSeek 发 release notes 把时间写在标题上，文章内部连时间戳都没有；他认为中国互联网内容缺少标准和规范，甚至“整个互联网内容其实不存在”。向阳乔木补充，中国是强烈依赖互联网 1.0 基建，而 1.0 那套基建很多人是跳过去的；2.0 时代曾有 RSS 和抓虾等阅读器，后来被大厂瓜分、封闭在自家系统。杨攀打算整理完优质 AI 信源后发布成 RSS，歸藏建议发 MCP，但杨攀认为 RSS 存在那里，Agent 自己会刷；向阳乔木装 RSS 订阅器最大的障碍是微信公众号，需要买抓取服务才能订阅卡兹克等人。大家还讨论微信公众号“原创”功能符合国情，海外更注重原创，国内洗稿野蛮；橘子说微信授权后同步腾讯新闻或小红书，也可以走 API 自动发布 RSS，但中文互联网整体缺少开放内容和服务。向阳乔木指出中国 Web 2.0 也做过 RSS，但赚不到钱，公众号才是国内自媒体头号盈利来源，国外 Substack、Newsletter、RSS 还能赚钱；杨攀说独立博客同样文章远不如公众号阅读量，但向阳乔木认为现在 Agent 在搜，反而存在套利，因为卡兹克只在公众号上，Agent 找不到，而有 blog 的向阳乔木内容会被 Agent 全读。

#### 云电脑、自己的电脑与服务器管理
歸藏大量使用 Dots 的虚拟机，把常用 CLI、GitHub、Cloudflare、Skill 都装上去，手机在外想到文案或信源，就让它在云端结合 Twitter 信息和 Skill 做图、做视频。连自己 Mac Studio 虽然可以，但要走 SSH、传文件、搭一堆东西，不如直接放云端；杨攀的 Dots 认为它有两台电脑：云端 computer 和杨攀的 Mac Studio，笔记本下任务时它会在 Mac Studio 上操作。歸藏说 Mac Studio 装了 Claude，很多其他东西不好装，而且不是人人都有一直开机的 Mac Studio，所以云电脑“不用白不用”。杨攀认为 Agent 认为只有两台电脑只是雏形，未来会管理 10 台、100 台电脑，甚至公司电脑、家庭电脑集群；Tibo 在播客里讲 Dots 未来就是管一堆电脑。杨攀国庆整理了家里 NUC、两个树莓派、三个派、NAS、六七个手机，问 Codex 能干啥没得到好建议；向阳乔木则写 Skill 管理多台 VPS，把 SSH 账号列出、生成 Key、本地免登录、命名 1 2 3 4，让 Agent 写服务器服务文档、重启修复、做多台容灾备份，感觉多了个运维工程师。橘子总结，这一波把“管理”放大：上一波 Codex 偏 build，中间一波是白领 work，这一波是个人管理、设备管理，管理需求比办公更大；Claude Code 和 Claude CodeWork 的合并、上云端也引发讨论，杨攀还提到身边能用 Claude 的人越来越少，期待 DeepSeek 变强。

#### 用 Opus 5.5 写游戏：代码质量与效率
杨攀去年 11 月写了游戏剧本和设定，一直没时间做，国庆用 Opus 5.5 直接读旧剧本开始写，出来的版本马上能玩，几乎没缺陷，再迭代几个版本。他的类比是：Opus 5.5 写游戏相当于年薪几百万的游戏公司 CTO 水平，干几十分钟相当于这种人干几个月；歸藏补充“半小时给你一个 demo，三天能上架”。杨攀没看代码，但看功能，并作为“老师傅”提性能调优和逻辑设定，Opus 5.5 会解释 CPU 耗时、屏幕刷新率、算法路径优化、赢回多少毫秒，非常专业。橘子说有人评价 Opus 5.5 以程序员角度，深度和广度已经超越旧程序员；以前模型功能能实现但代码一坨屎，专业程序员评价 Opus 5.5 里面也很优雅。橘子国庆在群里怼人，说“AI 在写屎山代码”是上个月认知，是没用过 Opus 5.5；OpenAI 的 Tibo 也预告后续模型会逐渐干掉屎山代码，不仅做出结果，中间过程也优化。杨攀引用 OpenAI 博客：今天直接实现想法，下个版本模型可把最简单实现优化成最优代码，所以永远用下一个版本的智能红利，今天赢得的是时间；歸藏还提到知乎问答“死人是不会说话的”。大家认为现在 AI 认知落后一周、一个月就很明显，上一波 GLM 5.3、K3、DeepSeek V3、Inflash 与 Opus 5.5 比，价格和智能又拉开；Opus token 效率极高，歸藏觉得 20 美金和 200 美金效果差不多，生成代码从过去输出 slop 到现在直捣黄龙、输出很少。歸藏说现在复杂项目会像 DeepSeek R1 阶段一样，50k token 一口气喷出来；Astra 和 Opus 点的科技树不同，Astra 偏 computer use、browser use、3D，Opus 偏视频和程序深度广度，有人做桥让 Claude 调 Codex，因为 MCP 一直广播、用 APP server 可调用，生图也能调。还有“邪修”用 Go 写前端；杨攀写游戏先用前端 Canvas，后 PixiJS 提性能，再问上 Steam 和 App Store，被告知可用 GoDot 引擎。向阳乔木把 Obsidian 插件迁到 DeepSeek Harness，让 AI 判断去掉笔记相关部分，全部迁过去，说明跨平台技术栈市场变小。

#### 迁移插件、替换编辑器内核
橘子重构 Markdown 编辑器，从 Milkdown 迁移到 CM6，用 DeepSeek Flash。AI 说工作量大，可能需要一周，橘子说“你是 AI，一天差不多”，结果真的写出来，虽然有些 bug。需求是原来渲染和源码两套，改东西看似改了、源码没改，想换成实时、源码为事实、一套，符合 Typora 等主流。换完解决一堆 bug，因为两套渲染细节太多；杨攀刷个人网站时顺手做了“杨攀版 Tailwind CSS”，把 token 提出来就完事。杨攀回忆三四年前 ChatGPT 3.5 时代，只能吐代码、放 Sublime 保存运行，现在提升巨大；橘子对换内核毫无认知，AI 提方案说换内核能解决一堆问题，她确认再三“我能 hold 住吗”，AI 说没问题。向阳乔木在 Chrome 商店上架很多插件，早三四年前 AI 写的和最近写的复杂度差别很大，最近能做原来不敢想象的东西；橘子说他那个“15”挺复杂，下载了不会用。杨攀看到向阳乔木国庆把 Obsidian 这条线做深做透，不像很多人东一榔头西一棒子；Obsidian 最近疯狂更新，支持不用进仓库直接编辑任何 Markdown，说了很久终于支持，因为开源竞品都这么干。杨攀说现在不需要 Obsidian，只需要它的组织方式，他的 Memory 文件夹就来自 Obsidian 文件夹；向阳乔木说 Obsidian 最大好处是上架程序、Mac/iPhone 同步、插件寄生开发生态、免审批审核，审核很快，群友提 bug 丢给 AI 修，10 分钟就能发布，像 GitHub，体验很爽。

#### Photoshop、重写软件与 GPL 讨论
杨攀说最近又炒起“Photoshop 要完蛋”，Adobe 旗下软件被网友用不完的 token 烧出一套 Adobe 生态。向阳乔木说 Adobe 组织有问题，早年跟 TikTok 合作，他们这边两三个人，Adobe 成立 war room，50 个人对接，事情其实非常简单；但 Adobe 的设计师真厉害，一个日本设计师把全套页面、交互流程画好、标注清楚，拿过来就能用，真正干活的可能就是日本设计师加他们，其他人是 stakeholders。橘子说有人当着 Adobe CEO 的面抄了一个 Photoshop，CEO 无话可说，因为是 AI 抄的，没有版权问题，没用代码，只是长得一样，无法起诉。杨攀有 GPL 协议项目，说直接用它、二进制引用或用代码都会受传染，于是让 Agent 参考它、蒸馏架构、自己复制一份、换套语言写，从而绕开版权；向阳乔木写电子书阅读器，看到一个俄罗斯小哥写得好，fork 后加功能想上架给朋友用，AI 说未经允许不能上架，最后从头写一份。杨攀建议不用参考代码，让 AI 把架构、理念、核心技术点 export 成文档或设计；向阳乔木说当时在原基础改，改到区别不大，AI 列工作任务，改到相似度 30%、10%，认为可以提交、不构成侵权。杨攀觉得现实世界说不清楚，但蒸馏架构从头写可行；橘子让 AI 加微信排版功能，AI 自动说已有项目、参考一下，杨攀接小米遥控器语音输入时也参考其他项目，提需求要脱离原依赖即可。向阳乔木问不懂技术的人让 AI 开发是否可能侵权；杨攀说 export 时除 APP 外还附加 legal 文档，写着因前面用 GPL，所以这个也应是 GPL，认为 Opus 5.5 深度广度够，一百种解法都给你。

#### 游戏反编译、Mod 与商业模式
向阳乔木说以后所有互联网创作结果都无法阻止别人复制和分发，合法情况下的复制分发都阻止不了，违法更不可能。AnyPS5 把 PS5 在 Windows X86 平台重新编译、全部重写，让 PS5 游戏能在 PC 运行；硬说侵权可能用了 PS5 源码参考，但结果跟 PS5 完全没关系，却能运行 PS5 游戏。索尼和任天堂最伤，国内二游核心是抽卡和账号所有权，复刻没关系，还能卖角色、皮肤；一次性售卖的精良大作受伤害最深。塞尔达、血源很多人复刻，血源进度一直不理想，最近两周进展神速，因为 Opus 5.5 直接反编译二进制；杨攀国庆用不完 token，做实验让 AI 把《金庸群侠传》机器码反编译成 C，再转其他语言，用原素材重写一遍做到一样。橘子说现在玩 AI 游戏不是 Web coding 从零写，而是拿现成游戏写 Mod 二创，比如马里奥放进《艾尔登法环》、《我的世界》做成《艾尔登法环》；Mod 原理是有些游戏本来就支持，尤其集成后交互一样，只改地图、奖励，改爽后可分发，已经被 hack 掉，Dota 当年就是从魔兽 3 地图起来的。杨攀认为每个人都能开发 APP 或游戏后，真正让好些人用上的还是各领域基础设施和 Harness，依赖它 build 之上的东西才能共用，剩下全是自己搞；向阳乔木问以后是不是特别卷、只有顶流活下来，歸藏说一定。橘子说商业模式得变，本地游戏可能变成 128 块联机游戏，二游卖新角色、更新、形象设计，而不是装备数值，数值没壁垒，形象设计也没壁垒，但需要共识，一个角色要大家认可；杨攀总结还是做好自己的 IP，IP 很重要，并让大家多支持 Next Token。

#### 推理优化与成本下降
橘子提到过去一周推理成本下降有巨大进展，叫 Strata，能把推理速度提升上百倍，直接导致 DGX 涨价。杨攀说涨价原因是花一份钱能力又提升，以前 4999 只能跑几十 token，现在能拉到几百 token、上千 token，相当于硬件无缘无故涨了十倍。这一波是用 C 专门针对某个模型架构重写，橘子说是 AI 写的算法，Opus 直接给自己降本，提升输出效率。歸藏猜测 Opus 5.5 模型并不小，但在推理速度和推理成果上找到了优化点。橘子还说 Opus 和 Gemini 4 缓存是 95% 打折，以前是 90%，成本降了；Gemini 4 发了像没发，只有 API 或 Auto。后半段转写出现大量重复和损坏，但时间轴显示还讨论了“成本、插件与小硬件”。
