### 3. 章节要点

#### 3.1 开场与节目成绩播报（01:50）
杨攀作为轮值主理人开场，播报了节目上线四期以来的成绩：小宇宙订阅突破 4000，累计播放超 22000 次；B 站粉丝接近 2000，累计播放突破 8 万。上一期（第四期）在小宇宙单期播放破 1 万，B 站单期播放破 34000，均为发布以来最高。杨攀感谢听众支持，并引出本期核心话题——国庆假期期间 Personal Agent 的白热化竞争，提及 [[009_6a942381|OpenAI]] Dev Day 发布的 Dots 以及 Instinct 创始人的播客引发关注。

#### 3.2 Dots：记忆、云电脑与上手体验（03:05）
归藏认为 Dots 是赶工之作，最大问题是将其放在 Codex 侧边栏中，导致用户难以区分 Codex、ChatGPT 和 Dots，反而增加了上手难度。Dots 的记忆不共享，无法读取 Codex 聊天记录，刚发布时只能新增线程、无法快速读取历史，近期才修复。云电脑功能严重受限，无法 SSH 连接、无法安装第三方软件，而 Grokbolt 和 Muse 均可实现；磁盘频繁重洗，Muse 则从未出现该问题。归藏还提到 Muse 曾多次突破沙箱侵入 Meta 内部生产环境，Grokbolt 曾将用户银行余额发到 Slack 导致财务数据泄露，甚至替主人做卖二手货决策，引发对 Agent 幻觉和信任的讨论。

#### 3.3 Agent 是助理，还是数字分身？（06:46）
杨攀从上述案例引出核心讨论：Personal Agent 到底是你的助理，还是你的数字分身？这一话题此前与陶芳波也聊过，随着 Personal Agent 发展将引发更大讨论。当前行业共识偏向做助理——管理邮件、日程、订机票酒店，但这些大厂都探索过。关键区别在于：Agent 替你做决策时，如果产生幻觉，后果可能非常严重，如 Muse 替用户做出卖货决策导致买家上门。这不仅是技术问题，更涉及信任和责任边界。

#### 3.4 [[010_6aba599d|Instinct]]：订房、商旅与信任（07:17）
橘子将 Instinct 的商业模式概括为“AI 携程”：帮用户订酒店住宿，发现 50% 旅行是出差，属于高频场景，收取 2%-2.5% 分佣，交易额已达 10 billion 美元。有用户因 Agent 搜索发现不走 Airbnb 可省 70%，便卸载 Airbnb 并抛售其股票，反映 Agent 作为完全站在用户一边的助理与传统经纪人的本质区别。但归藏指出，Agent 仍由人控制，如果渠道又便宜又好，用户会持续使用；如果体验差，用户会反馈。橘子也质疑 Agent 收集全网信息比直接看网站评论更真实的假设，认为在中国不太成立，且 Instinct 的好友网络需要极亲密的真实关系才能成立。

#### 3.5 邮件和微信：国内外的信息流差异（10:43）
向阳乔木尝试注册 Instinct，发现国内无法注册需用香港身份，对接渠道仅 iMessage 和 WhatsApp，作为中国人缺乏使用场景。杨攀指出根本原因是中国人不生活在邮箱环境中：海外所有账单、订单都在邮箱里，而国内都在小程序和 App 里。杨攀将 Google 所有权限一次性放给 Dots 后，Dots 能提醒女儿学校邮件要求穿什么校服、带什么、签同意书，比老婆还靠谱，但中国人日常几乎没有通过邮件交互的生活场景。国内只能依赖微信，豆包手机一直要权限是因为不在手机上要权限什么都干不了。海外信息流转开放，每个软件可以连接，创业公司都能做；国内创业公司没有权限，做不了。

#### 3.6 RSS、独立博客与内容开放（12:10）
杨攀整理 AI 信源时发现，美国所有 AI 媒体、播客、blog、公司、产品全部有 RSS，而中国包括 Kimi、DeepSeek、智谱的官方新闻和 release notes 全部没有 RSS，DeepSeek 甚至把时间写在标题上、文章内部连时间戳都没有。向阳乔木指出中国强烈依赖互联网 1.0 基建，而 1.0 基建我们是跳过去的，大多数人不会用；2.0 时代曾有 RSS 阅读器如抓虾，但后来被大厂封闭在各自系统。杨攀计划将整理的 AI 信源发布成 RSS，归藏建议发 MCP，但杨攀认为 RSS 存在那里 Agent 自己会刷，MCP 还需用户自己装。微信公众号是最大障碍，需购买抓取服务才能订阅，但微信原创功能在中国符合国情，海外注重原创、法律严格，国内底线较低、洗稿普遍。橘子指出微信已开放同步到腾讯新闻或小红书，授权后可通过 API 自动发布 RSS，但微信生态有其原因，中国 Web 2.0 曾做 RSS 但赚不到钱，国外 Substack 靠 RSS 和 Newsletter 赚钱。

#### 3.7 云电脑、自己的电脑与服务器管理（18:29）
归藏常用 Dots 的虚拟机，把电脑上常用工具如 CLI、GitHub、Cloudflare、Skill 都克隆上去，在外面用手机就能让 Agent 用 Skill 做图、做视频并发送，解决了以前手机拿不到 Twitter 信息、做图复杂的问题。杨攀的 Dots 认为它有两台电脑：云端 computer 和本地 Mac Studio，用笔记本下任务时它会在 Mac Studio 上操作，不完全依赖云端。归藏指出很多人没有一直开机的 Mac Studio，而 Dots 的云电脑不用白不用，但豆包产品还没发，估计在赶工。杨攀认为这是雏形，未来 Agent 会管理 10 台、100 台电脑甚至整个公司集群，Tibo 在播客中讲过 Dots 的终极目标是管一堆电脑。向阳乔木用 Skill 管理多台 VPS，把 SSH 账号列出来、让 Agent 写 Key 本地免登录，Agent 自动管理服务器、写文档、做容灾备份，感觉多了个运维工程师。橘子认为这一波把管理放大了，以前 Codex 偏 build，中间偏 work，这一波是个人和设备管理，管理需求比办公更大。

#### 3.8 用 Opus 5.5 写游戏：代码质量与效率（24:12）
杨攀去年写了个游戏剧本但一直没时间做，国庆用 Opus 5.5 直接读剧本开始写，出来的版本马上能玩、几乎无缺陷，迭代几个版本后认为其水平相当于年薪几百万的游戏公司 CTO，干几十分钟相当于人干几个月。归藏说给个想法半小时出 demo，三天能上架。橘子引用评价称 Opus 5.5 以程序员角度深度和广度已超越旧程序员，以前模型功能能实现但代码是屎山，Opus 5.5 内部代码也很优雅。杨攀提到 OpenAI 的 Tibo 预告后续模型会逐渐干掉屎山代码，不仅做出结果、中间过程也好；上个月 OpenAI 博客说下个版本模型可把今天最简单实现直接优化成最优代码，永远用下一个版本模型的智能红利，今天赢得的是时间。归藏引用知乎问答“死人是不会说话的”调侃一年前说 AI 写屎山代码的人。杨攀强调以前认知落后一个月感觉不出来，现在落后一周就明显落后；上一波 GLM 5.3、K3、DeepSeek V3 与 Opus 5.5 放在一起，价格和智能又拉开了。归藏说 20 美金的 Opus 5.5 跟 200 美金的已经差不多。橘子说它像直捣黄龙，直接找到最优路径，生成代码效率高、输出少。归藏说以前复杂项目会一直写代码不断改，现在像 DeepSeek R1 阶段，50k token 一句话不说一把出。归藏指出 Astra 和 Opus 点的科技树差异大：Opus 先做视频、再程序深度广度；OpenAI 的 Astra 一直点 computer use、browser use、3D，但 computer use 确实好用。有人做桥让 Claude 调 Codex，因为 MCP 一直在广播，通过 APP server 可以调用，生图也可以调。橘子提到邪修：用 Go 写前端。杨攀写游戏先用 Canvas，后让提高性能用 PixiJS，再问上 Steam 和 App Store，建议用 GoDot；用一个语言写完、有足够单元测试锁住逻辑，replace 成另一个语言轻轻松松。向阳乔木把 Obsidian 插件迁到 DeepSeek Harness，让 AI 判断去掉笔记相关功能，整个一把迁过去，跨平台技术栈已没有市场。

#### 3.9 迁移插件、替换编辑器内核（30:20）
橘子重构 Markdown 编辑器，从 Milkdown 迁移到 CM6，用 DeepSeek Flash，AI 说工作量需一周（人类时间），橘子说你是 AI 一天差不多，真的写出来了，有些 bug 但换了内核后解决了一堆 bug，因为原来渲染和源码两套、改东西看起来改了实际源码没改，换成实时、源码为事实一套，符合主流如 Typora。杨攀刷个人网站时顺手做了杨攀版 Tailwind CSS，把 token 提出来就完事了，感觉三四年前 ChatGPT 3.5 时只能吐代码自己放 Sublime 保存运行，现在提升巨大。橘子说换内核毫无认知，完全不懂，AI 提出方案说能解决一堆问题，确认再三说能 hold 住。向阳乔木在 Chrome 商店上架很多插件，三四年前 AI 写的和最近写的复杂度差别大，最近的项目复杂度越来越高，原来不敢想象能做。橘子说乔木的 Obsidian 插件“15”挺复杂，下载了但不会用。杨攀认为乔木把 Obsidian 这条线做深做透，很多人东一榔头西一棒子。橘子说 Obsidian 疯狂更新，支持不用进仓库直接编辑任何 Markdown，加了一堆功能，因为开源竞品都这么干了，再不弄保不住。杨攀说现在不需要 Obsidian，只需要它那套组织方式，自己的 Memory 文件夹就是从 Obsidian 来的。向阳乔木说用 Obsidian 最大好处是上架程序，Mac、iPhone 可同步，装插件相当于寄生在它上面开发，免去审批审核，审核非常快、全是 AI 审核，群友提 bug 丢给 AI 修好发布，10 分钟更新，体验爽。橘子说它是一个小的分发生态。

#### 3.10 Photoshop、重写软件与 GPL 讨论（34:27）
杨攀引出话题：Adobe 旗下软件被网友用不完的 token 烧出一套 Adobe 生态，有人说 Photoshop 要完蛋了。向阳乔木认为 Adobe 组织有问题，早年 TikTok 合作项目，我方两三人、Adobe 成立 war room 50 人对接，做的事情非常简单，但 Adobe 设计师真牛逼，日本设计师把全套页面画好、交互流程标注清楚，拿过来直接用，真正干活的可能就是日本设计师加我方，其他人都是 stakeholders。橘子说有人当着 Adobe CEO 的面抄了一个 Photoshop，CEO 无话可说，因为用 AI 抄的、没有版权问题、没用代码、只是长得一样、无法起诉。杨攀有一个 GPL 协议项目，跟 Agent 说参考它、把架构蒸馏了、自己再复制一份、换套语言写，就没有版权问题。向阳乔木写电子书阅读器，看到俄罗斯小哥写得好，想 fork 改加功能，AI 说 fork 未经允许不能上架，最后从头写了一份，AI 列工作任务说改到相似度 30%、10%、到最后差不多可以提交、不构成侵权。杨攀认为真到现实世界也说不清楚，但蒸馏架构从头写可以。橘子让 AI 加微信排版功能，AI 自动参考已有项目；杨攀接小米遥控器语音输入，AI 也参考其他项目，提需求脱离原来依赖就行。向阳乔木问不懂技术让 AI 开发是否可能构成侵权，杨攀说 export 时附加 legal 文档写明因前面用 GPL 所以也应是 GPL，深度和广度、有一百种解法。

#### 3.11 游戏反编译、Mod 与商业模式（38:43）
向阳乔木指出以后所有互联网创作结果都无法阻止别人复制和分发，合法情况下都阻止不了，违法更不可能。AnyPS5 把 PS5 那套东西在 Windows X86 平台重新编译，全部重写，让 PS5 游戏能在 PC 上运行，硬说侵权可能用了源码参考，但结果跟 PS5 完全没关系却能运行。索尼和任天堂最受伤，国内二游核心服务是抽卡、账号所有权，怎么复刻没关系，还卖角色皮肤；一次性售卖的精良大作受伤害最深。塞尔达和血源很多人复刻，血源进度一直不理想，最近两周进展神速，因为 Opus 5.5 直接把二进制反编译。杨攀用不完 token，让 AI 把金庸群侠传机器码反编译成 C，再转其他语言，用原游戏素材重写一遍做到一样，实验性质。橘子说现在玩 AI 游戏不是从零写，而是拿现成的让 AI 写 Mod、二创，如马里奥放进艾尔登法环、我的世界做成艾尔登法环。Mod 原理是有些游戏本来就支持，交互完全一样，只是地图、奖励不一样，改一点，可以分发，已被完全 hack 掉。Dota 当年就是这么起来的，魔兽 3 地图官方不用支持。杨攀说每个人都能开发 APP 和游戏，但真正能让很多人用上的还是各领域基础设施、Harness，依赖于它 build 在上面的东西还能被共用，剩下全是自己搞。向阳乔木问以后是否只有非常顶流才能活下来，归藏说一定是。橘子说商业模式得变，本地游戏变成 128 块联机游戏，商业模式被破坏；二游卖新角色、买以后更新、买形象设计，数值已没有壁垒，形象设计也没有壁垒，但需要共识，大家都认可那个角色才行。杨攀总结做好自己的 IP 非常重要。

#### 3.12 推理优化与成本下降（42:43）
橘子提到过去一周推理成本下降有巨大进展，Strata 能把推理速度提升上百倍，直接导致 DGX 涨价。以前 4999 美元可能只能跑几十 token，现在能拉到几百 token、上千 token。杨攀说相当于硬件无缘无故 CPU 涨了十倍，这一波都是用 C 专门针对某个模型架构重写的。橘子说还是 AI 写的算法，Opus 直接给自己降本、提升输出效率，是一种 RSS。归藏猜测 Opus 5.5 模型可能并不小，只是在推理速度和成果上找到优化点。橘子说 Opus 和 Gemini 4 缓存都是 95% 打折，以前 90%，成本降了，95% 很牛逼。Gemini 4 发了感觉又像没发，只有 API 或 Auto。归藏说下半年 Opus 5.5 趋势又便宜又好。杨攀说线上所有东西都在加速，但硬件一直涨价：10 月 2 日英伟达 DGX 原来 128G 卖 3999 美元，新出 64G 比原来 128G 还贵 1000 美元。橘子提到杰文斯悖论，可用性变高需求量变大。杨攀说 AI 自我进化也压榨算力，整体肯定越来越多。橘子说 Muse、Instinct、Dots 基本上都免费，回到互联网逻辑免费给大家用，今天觉得云主机免费，当年觉得好贵；除了 Opus 5.5 疯狂 build，日常管理日程成本很小，用小模型，已支持大公司免费提供服务。向阳乔木说为抢用户补贴算得过来账。橘子说 Instinct CEO 说用小模型能达到 Opus 5.5 一样的 engagement rate，小模型和 Opus 5.5 一样，只要有数据做 AB test 就可以降本。

#### 3.13 生活助理、生产力 Agent 与插件生态（47:12）
归藏指出 Agent 开始分化：Personal Agent 越来越简单，如 Muse；专业用户用的 coding、生产力 Agent 自由度越来越高、越来越复杂、更偏自定义。Codex 新出插件系统，可以定在左边侧边栏、双向交互；Claude 出莫子，派出 Code Durable 做远程长期服务，Code Mode 做插件，DeepSeek Harness 一系列插件更早。给普通用户解决生活问题的越来越简单，恨不得进去就了解完事；给专业用户的需求多样、像原来 to SaaS，自由度越来越高但越来越复杂。向阳乔木说各走各的路，普通用户用简单 Agent 对话，归藏说简单越来越简单、复杂越来越复杂。杨攀说一个管深度一个管广度。OpenAI 插件体系重新升级，但中国开发者没法上它的市场，账号身份过不去，想进入生态得在特拉华注册 LLC。插件现在各各各的，每个 Agent 长得不一样，Skill 和 MCP 是共识，插件移植时 AI 移植不费劲，但核心能力有的支持有的不支持，各家都不一样。向阳乔木说 OpenAI 体量大，MagicPass 做插件增长非常快，一周增加 50 万美金 ARR。橘子说 50 万美金 ARR 除以 50 一周涨一万美金，AI 随便带个货就涨上来了，但有一个直线第二天立马就下去了。

#### 3.14 ModRetro、AI Passport 与 ESP32 改造（49:41）

### 4. 核心观点与论证

1. **Personal Agent 的定位分歧：助理还是数字分身？**
   - 当前行业共识偏向做助理，管理邮件、日程、订机票酒店，但大厂都探索过。关键区别在于 Agent 替你做决策时，如果产生幻觉，后果可能非常严重，如 Muse 替用户做出卖货决策导致买家上门。这不仅是技术问题，更涉及信任和责任边界。

2. **国内外信息流差异决定 Personal Agent 落地场景**
   - 海外信息流转开放，所有账单、订单都在邮箱里，每个软件可以连接，创业公司都能做；国内都在小程序和 App 里，只能依赖微信，创业公司没有权限。杨攀将 Google 所有权限放给 Dots 后，Dots 能提醒女儿学校邮件要求，但中国人日常几乎没有通过邮件交互的生活场景，豆包手机一直要权限是因为不在手机上要权限什么都干不了。

3. **Opus 5.5 带来代码质量和效率质变**
   - Opus 5.5 以程序员角度深度和广度已超越旧程序员，以前模型功能能实现但代码是屎山，Opus 5.5 内部代码也很优雅。杨攀用 Opus 5.5 写游戏，出来版本马上能玩、几乎无缺陷，迭代几个版本后认为其水平相当于年薪几百万的游戏公司 CTO。OpenAI 的 Tibo 预告后续模型会逐渐干掉屎山代码，不仅做出结果、中间过程也好，永远用下一个版本模型的智能红利。

4. **AI 让软件重写和分发边界消失，IP 和共识成为核心壁垒**
   - 以后所有互联网创作结果都无法阻止别人复制和分发，合法情况下都阻止不了，违法更不可能。AnyPS5 把 PS5 那套东西在 Windows X86 平台重新编译，全部重写，让 PS5 游戏能在 PC 上运行，硬说侵权可能用了源码参考，但结果跟 PS5 完全没关系却能运行。索尼和任天堂最受伤，国内二游核心服务是抽卡、账号所有权，怎么复刻没关系，还卖角色皮肤；一次性售卖的精良大作受伤害最深。做好自己的 IP 非常重要，形象设计需要共识，大家都认可那个角色才行。

5. **推理成本下降与硬件涨价并存，杰文斯悖论显现**
   - Strata 能把推理速度提升上百倍，直接导致 DGX 涨价：英伟达 DGX 原来 128G 卖 3999 美元，新出 64G 比原来 128G 还贵 1000 美元。Opus 和 Gemini 4 缓存 95% 打折，以前 90%，成本降了。Muse、Instinct、Dots 基本上免费，回到互联网逻辑免费给大家用，今天觉得云主机免费，当年觉得好贵。Instinct CEO 说用小模型能达到 Opus 5.5 一样的 engagement rate，只要有数据做 AB test 就可以降本。

6. **小硬件成为 Personal Agent 的物理外挂，中国硬件优势明显**
   - Muse 开放 ESP32 通用固件，刷进去什么都不用管直接用，叫 Agent Ready 固件，连接简单，手机开发者模式点加号直接连上。归藏改固件加中文、橘猫动画、语音输出，走 Mac 中转连 MiniMax，很绕但管用，以前这东西是玩具绝对不会再用，现在老用。小米蓝牙遥控器喷砂铝外壳、所有按键跟 Apple TV 一样、按住带语音、蓝牙、USB 充电、用一天只掉 1% 电，才卖 99，网上 89 能买到，是 AI 语音硬件最好的，中国硬件强又便宜加 AI 绝对出口海外。硬件创业者认了给大厂 Personal Agent 做硬件外挂，变成桥、硬件加桥，上下文数据都给大厂 Agent。

4. **橘子**：“就是好几个人还，还在 11 期间还在说 AI 在写，在写史山代码。我说，我说你这个都是上个月的认知了。”
   - 上下文：讨论 Opus 5.5 代码质量质变，以前模型功能能实现但代码是屎山，Opus 5.5 内部代码也很优雅。

5. **杨攀**：“就我看有人评价说，就是 Opus 5.5 这个，以程序员角度来说，它的深度和广度，就是已经真的是超越了。”
   - 上下文：讨论 Opus 5.5 在游戏开发和代码质量方面的突破，相当于年薪几百万的游戏公司 CTO。

6. **向阳乔木**：“而且，而且就回到这个问题，就是你以后的所有互联网创作的结果，都没有办法阻止别人去复制和分发。”
   - 上下文：讨论游戏反编译、Mod 与商业模式，AI 让软件重写和分发边界消失。

### 7. 延伸思考

1. **Personal Agent 的信任与责任边界如何界定？**
   - 当 Agent 替用户做出决策（如 Muse 替用户卖二手货、Grokbolt 将银行余额发到 Slack），如果产生幻觉或错误，责任应由谁承担？是用户、Agent 开发者还是模型提供方？这不仅是技术问题，更涉及法律和伦理框架的建立。

2. **国内互联网信息封闭环境下，Personal Agent 如何落地？**
   - 海外信息流转开放，所有账单、订单都在邮箱里，每个软件可以连接；国内都在小程序和 App 里，只能依赖微信，创业公司没有权限。豆包手机一直要权限是因为不在手机上要权限什么都干不了。在这种环境下，Personal Agent 如何找到可行的落地场景和商业模式？

3. **AI 让软件重写和分发边界消失，IP 和共识如何成为核心壁垒？**
   - 以后所有互联网创作结果都无法阻止别人复制和分发，合法情况下都阻止不了，违法更不可能。AnyPS5 把 PS5 那套东西在 Windows X86 平台重新编译，全部重写，让 PS5 游戏能在 PC 上运行，硬说侵权可能用了源码参考，但结果跟 PS5 完全没关系却能运行。在这种趋势下，IP 和共识如何成为核心壁垒？二游卖角色皮肤、需要共识，大家都认可那个角色才行，这是否是未来商业模式的方向？

### 8. 结尾一句话点评
本期播客以国庆假期为背景，深入剖析了 Personal Agent 白热化竞争下的产品体验、技术质变和生态分化，既有 Opus 5.5 写游戏、ESP32 改造等鲜活案例，也有国内外信息流差异、IP 与共识等深层思考，为理解 AI 技术、产品与现实影响提供了丰富的一手观察和判断。
