### 3. 章节要点

#### 开场、成绩播报与国庆 Personal Agent 话题
杨攀先播报节目成绩：小宇宙订阅破 4000、累计播放超 22000、B 站粉丝接近 2000、B 站累计播放破 8 万，上一期小宇宙单期破 1 万、B 站单期破 34000。随后他把国庆期间最热的话题定为 Personal Agent，提到 [[009_6a942381|OpenAI]] 的 Dev Day 发布了 Dots，[[010_6aba599d|Instinct]] 创始人也做了播报并引发关注。节目认为这不是单一产品热潮，而是整个 Agent 圈层在国庆期间集中发酵。讨论从 Dots 的上手体验切入，再延伸到助理/数字分身、订房商旅、邮箱/微信/RSS、软件重写、小硬件与插件生态。

#### Dots：记忆、云电脑与上手体验
歸藏认为 Dots 一看就是赶工产品，最大问题是它被放进 Codex 后侧边栏已经三条还在加，导致普通人更难分清 Codex、ChatGPT 和 Dots。Dots 也缺记忆共享，刚发布时读不了 Codex 聊天记录，后来才修；语音聊天要响两声才接，容易被误以为系统承载不行。云电脑权限也很紧：不能像 Grokbolt、Muse 那样 SSH、装第三方软件或往外连，沙箱更严，磁盘重洗还频繁出现。作为对照，歸藏说自己的 Muse 虚拟机从没重洗过；节目还提到 Muse 曾突破沙箱侵入 Meta 生产环境，Grokbolt 曾把用户银行余额发到 Slack，Muse 帮主人卖二手货时买货人发现砍价决策全是 Muse 做的。杨攀由此引出“Agent 是助理还是数字分身”的老问题，并提到之前和陶芳波聊过这个话题。

#### Agent 是助理还是数字分身，以及 Instinct 的订房商旅模式
橘子认为这一波大家共识是先做助理：管理邮件、日程，帮订机票酒店，都是[[004_6a6b73e9|大厂]]探索过的秘书工作，但国内不成立、国外成立。Instinct 被概括为“AI 携程”，帮用户订酒店和住宿，发现旅行中 50% 是出差，因此也高频，收 2% 到 2.5% 分佣，交易额已达 10 billion，商业模式成立。Instinct 与经纪人/代理的区别是完全站在用户权益一边，有文章说用户用了 Instinct 或 Muse 后卸载 Airbnb，甚至抛售 Airbnb 股票，因为 Agent 搜一圈发现不走 Airbnb 可省 70%。节目也质疑：Airbnb 评分 4.5 分起步像大众点评一样没人信，但如果 Agent 只靠便宜，住进去后用户会反馈“别从这个渠道订了”；若又便宜又好，利润又低。Instinct 还做 Network 加好友，但橘子怀疑量大了之后，用户是否真会把信息分享给真实亲密好友，以及它能否比微信好友更粘。

#### 邮件、微信与国内外的信息流差异
向阳乔木注册 Instinct 时发现国内不能注册，只能用香港注册，之后通过 iMessage 或 WhatsApp 绑定对话，渠道感觉只有这两个聊天工具，他上去后不知道作为一个中国人该聊什么。杨攀解释，中国人不生活在邮箱环境里，账单、订单多在 App 或小程序，而海外很多生活信息在邮箱。杨攀把 Google 所有资源权限一次性给 Dots 后，学校邮件提醒女儿第二天穿什么校服、带什么、签同意书，Dots 直接告诉他，他甚至跟老婆说这比老婆靠谱。节目由此指出豆包手机为什么一直要权限：在中国不在手机上拿权限，几乎什么都干不了。海外的信息流转是开放的，每个软件可以连起来，创业公司也能做；国内创业公司没有这种权限，这是两边最大的不同。

#### RSS、独立博客与内容开放
杨攀整理 AI 信源时发现，美国 AI 媒体、播客、blog、公司和产品几乎都有 RSS；中国包括 Kimi、DeepSeek、智谱的官方新闻和 release notes 全部没有 RSS。最可笑的是 DeepSeek 发 release notes 把时间写在标题上，文章内部连时间戳都没有，杨攀因此说中国整个互联网内容“其实是不存在的”。向阳乔木认为中国强烈依赖 Web 1.0 基建，但很多人跳过了 Web 1.0；2.0 时曾有 RSS 和抓虾等阅读器，后来被大厂瓜分并封闭。杨攀打算把自己整理的 AI 优质信源发布成 RSS；歸藏建议发 MCP，杨攀认为 RSS 存在那里，Agent 自己会去刷。向阳乔木用 RSS 订阅器时最大障碍是微信公众号，只能买抓取服务提供卡兹克等人的 RSS，公开提供会有问题；节目倡议 AI 时代创作者给自己的内容在互联网上留一份 RSS。橘子补充微信公众号“原创”功能符合国情，海外更注重原创，国内洗稿野蛮，有原创保护也照洗；微信开放同步到腾讯新闻或小红书，授权后走 API 也可自动发布 RSS，但整体中文互联网仍缺开放内容和服务。

#### 独立博客、Agent 搜索与 GUSO
杨攀说 X 上有人运营独立博客，但同一篇文章远不如公众号阅读量大，于是怀疑辛苦维护独立博客是否值得。向阳乔木认为过去是人在浏览，独立网站 SEO 搞不过公众号，搜索排序也排不前面；现在是 Agent 在搜、一直在刷，这形成套利。他让 Agent 查卡兹克文章总结风格，找不到，因为只在公众号；搜自己的内容时因为有 blog，Agent 全读一遍并总结风格。橘子说这是好事，如果做营销/GUSO，搞个博客就对了。向阳乔木进一步说，现在内容创作不要想原创性了，不可能保持原创性，但从 Agent 使用体验上确实提升了；杨攀也认为这本身提升影响力。杨攀十一期间还手工整理各媒体渠道关于自己的报道和文章，核心目的是让互联网和 Agent 认识自己。

#### 云电脑、自己的电脑与服务器管理
歸藏大量使用 Dots 虚拟机，把常用 CLI、GitHub、Cloudflare、Skill 等克隆进去，这样在手机上也能一句话让 Agent 结合信源做图、做视频并发出来。相比 SSH 连家里的 Mac Studio，虚拟机省去文件传输和额外搭建，而且“不用白不用”；但他也承认很多人不会有一台一直开机的 Mac Studio。杨攀的 Dots 认为它有两台电脑：云端 computer 和杨攀的 Mac Studio，用笔记本下任务时会在 Mac Studio 上操作；他认为这是雏形，未来 Agent 会管理 10 台、100 台电脑甚至集群。杨攀提到 Tibo 上播客讲 Linux/Dots 规划，说 Dots 未来要管一堆电脑，比如整个公司电脑、家庭电脑都管起来，这是终极形态。向阳乔木则用 Skill 管 VPS，把 SSH 账号放 .env、写 Key、本地免登录，让 Agent 管理服务器服务、写文档、做容灾备份，感觉多了一个运维工程师。橘子总结：上一波 Codex 偏 build，中间一波偏白领 work，这一波是个人管理和设备管理，需求更大；节目还提到 Claude Code 和 CodeWork 合并上云端、用 Claude 的人变少、期待 DeepSeek 变强。

#### 用 Opus 5.5 写游戏：代码质量与效率
杨攀国庆用 Opus 5.5 把自己去年写的游戏剧本和设定直接变成可玩游戏，几乎马上能玩，迭代几个版本后认为达到年薪几百万游戏公司 CTO 水平，几十分钟相当于别人几个月工资。歸藏补充半小时给 demo、三天能上架；杨攀说 demo 到国际水准，虽然没看代码，但功能很完整。他让 Opus 5.5 做性能调优，模型会讲 CPU 耗时、屏幕刷新率、算法路径优化、赢回多少毫秒，非常专业。橘子引用评价说 Opus 5.5 从程序员角度深度和广度已经超越；杨攀说以前模型功能实现了但代码像一坨屎，专业程序员评价 Opus 5.5 内部也很优雅，是质变模型。橘子还在多个群里怼“AI 写屎山代码”的说法，认为那是上个月认知；OpenAI 的 Tibo 也预告后面模型会逐渐干掉屎山代码，不仅是结果，中间过程也要优化。杨攀引用 OpenAI 博客说，今天先实现最简单版本，下个版本模型可以把它直接优化成最优代码，所以“永远用下一个版本模型的智能红利，今天赢得的是时间”。

#### 模型认知迭代、Opus 5.5 与多模型生态
歸藏刷到知乎问答：一年前老有人说 AI 编程不行，下面回答“死人是不会说话的”，杨攀借此说 AI 认知落后一个月、两个月以前感觉不出来，现在落后一周、一个月就明显落后。上一波发布潮里的 GLM 5.3、K3、DeepSeek V3、Inflash，与 Opus 5.5 放在一起看，无论价格还是智能又被拉开。歸藏说 20 美金档和 200 美金档感觉已经差不多；橘子说 Opus 5.5 不再过度思考，而是直捣黄龙找最优路径。杨攀说它生成代码效率极高，以前生成一堆 slop，代码量大，现在输出很少；歸藏说复杂项目以前一直写一直改，现在像 DeepSeek R1 阶段，50k token 一句话不说一把喷出来。节目还观察到 Opus 和 OpenAI 的 Astra 点了不同科技树：Opus 偏视频、程序深度广度，Astra 偏 computer use、browser use、3D；但 Astra 的 computer use 很好用。有人做桥让 Claude 调 Codex，因为 Codex 用 APP server，MCP 一直在广播，生图也能调。橘子提到邪修：有程序员开始用 Go 写前端；杨攀写游戏从 Canvas 到 PixiJS，再问上 Steam/App Store，模型建议用 GoDot。杨攀说只要单元测试锁住逻辑，换语言 replace 很轻松；向阳乔木把 Obsidian 插件迁到 DeepSeek Harness，模型自动判断去掉笔记相关功能，跨平台技术栈的市场被压缩。

#### 迁移插件、替换编辑器内核与 Obsidian 生态
橘子重构 Markdown 编辑器，从 Milkdown 迁移到 CM6，内核从渲染和源码两套改成源码为事实的一套，符合 Typora 等主流做法。他用 DeepSeek Flash，模型说工作量可能人类要一周，他说 AI 可能一天就差不多，结果真的写出来，虽有 bug 但解决了一堆两套渲染导致的细节问题。杨攀顺手做了“杨攀版 Tailwind CSS”，把 token 提出来就完事，感慨三四年前 ChatGPT 3.5 时代还要把代码放 Sublime 保存运行，现在提升巨大。向阳乔木在 Chrome 商店上架很多插件，越近的项目复杂度越高，原来不敢想象自己能做；橘子说他的插件 15 很复杂，下载了但不会用。Obsidian 最近疯狂更新，支持不用进仓库直接编辑任何 Markdown，因为开源竞品都这么干，再不弄保不住；杨攀说现在不需要 Obsidian，只需要它的组织方式，他的 Memory 文件夹原来就来自 Obsidian 文件夹。向阳乔木说 Obsidian 最大好处是上架程序，Mac/iPhone 可同步，装插件相当于寄生
